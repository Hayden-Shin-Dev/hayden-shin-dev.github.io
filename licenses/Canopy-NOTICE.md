# 외부 자료와 이용 조건

## 적용 범위

[루트 저작권 고지](LICENSE)는 신민철 본인의 원저작물에 관한 고지입니다
외부 라이브러리와 공동 작업자 자료의 권리를 대신 주장하거나 기존 라이선스를 바꾸지 않습니다
공개 열람 가능 여부와 자유로운 재사용 허가는 구분합니다

GitHub 공개 저장소에서의 열람·fork에는 GitHub 서비스 약관이 적용됩니다
[GitHub 라이선스 안내](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)

## 라이브러리

React·React Native·Expo·scikit-learn·pandas·Azure SDK 등 의존성의 저작권과 라이선스는 각 제공자에게 유지됩니다
패키지를 설치하면 배포 패키지에 포함된 LICENSE·NOTICE가 함께 적용됩니다
패키지 소스와 node_modules를 본인 저작물로 묶어 재배포하지 않습니다

정확한 버전은 [앱 잠금 파일](apps/ios/package-lock.json), [Python 의존성](requirements.txt), [API 의존성](apps/api/requirements.txt)에 기록했습니다
[의존성 선언별 라이선스 목록](docs/project/dependencies.csv)은 문서화 보조 자료이며 원문 라이선스를 대체하지 않습니다

## 프로젝트 시각 자료

마스코트·배경은 사용자 제공 자료와 프로젝트의 생성형 이미지 제작·편집 과정을 통해 앱에 적용한 자료입니다
이를 외부 라이브러리와 혼동하거나 제3자의 독점 권리까지 주장하지 않습니다
화면 캡처는 2026-10-01 현재 UI 미리보기에서 촬영했으며 예시 데이터를 사용합니다

브랜드 상품 이미지는 공개본에 포함하지 않고 일반 상품 표시로 대체했습니다
제휴 또는 실제 상품권 발급사의 연동 승인을 의미하지 않습니다
