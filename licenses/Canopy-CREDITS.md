# 프로젝트 기여와 출처

Canopy는 신민철이 기획하고 개인 PoC를 개발한 뒤 팀 프로젝트로 확장한 서비스입니다
신민철의 담당 범위는 [README](README.md)와 [구현 문서](docs/project/01-product-and-models.md)에 정리했습니다

## 공동 개발

최종 앱과 데이터 플랫폼에는 팀의 공동 작업이 포함됩니다
가져온 경로의 Git 이력에서 확인되는 작성자 표기는 다음과 같습니다
동일인의 여러 Git 표기가 있을 수 있으며, 계정별 코드량을 성과 지표로 사용하지 않습니다

이 저장소의 공개 스냅샷 커밋은 정리·반입 작업입니다
반입된 파일 전체의 최초 작성자가 해당 커밋 작성자라는 뜻은 아닙니다
팀의 주간 분석·보상 정책·최종 파이프라인 정리 기여를 개인 단독 개발로 재표기하지 않습니다

파일별 원본 해시와 공개본 해시는 [소스 스냅샷 목록](docs/project/source-snapshot.json)에 보존합니다
원래 작성자·날짜·커밋 해시를 유지한 전체 통합 이력은 비공개 보존본으로 분리했습니다
팀 PR·리뷰 대화는 원본 GitHub 저장소에 남아 있으며 Git 커밋 복사만으로 이전되지 않습니다
